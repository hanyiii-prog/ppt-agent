## 批 1 交付明细
- 新建模块（全部零第三方依赖，纯 stdlib 聚合）：
  - `design_dna.py`：`build_design_dna()` 把 v0.4 deck dict 聚合为 v1.0（v0.4 全键保留），产出 shape/layout/typography/color 四段命名设计 DNA；母版占位符不参与 margins/safe-area（内容定位只看 slide-origin）。
  - `semantic_role.py`：15 类语义角色（title/logo/decoration/...），`infer_semantic_role()` 强信号优先规则，`annotate_deck_dna()` 全栈非破坏标注。
  - `element_library.py`：无名身份签名（element|prstGeom|fill|line|尺寸桶），`build_element_library()` 跨页复用元素 + reuse_score = 0.6·出现量 + 0.4·页覆盖。
  - `spacing_graph.py`：水平/垂直 gap 聚类（0.05in 网格，count≥2 才算 dominant）。
  - `alignment_graph.py`：左中右/上中下六轴对齐线聚类（0.06in 容差）。
  - `design_rules.py`：`build_design_rules()` 合成 design-rules/v1 规则书；`validate_design()` 三类检查 R-TYPO-001 / R-COLOR-001 / R-SPACING-001，发现必带 detail。
  - `component_library.py`：元素签名共现 + 并查集聚类 → 复用组件（≥2 签名、≥2 页、覆盖率≥0.7）。
- 契约：`contracts.py` 新增 `TEMPLATE_DNA_SCHEMA_VERSION="1.0"`、`SUPPORTED_TEMPLATE_DNA_VERSIONS=("0.4","1.0")`、`check_template_dna_version()`（解析容忍 `v` 前缀）、descriptor 扩展两字段。
- 测试：`tests/design_dna_fixtures.py` 程序化迷你模板（母版占位符为真材实料）+ 5 个测试文件 25 项。
- 已知取舍：typography scale 有序指派（display→caption 单调）；spacing dominant 需同值 gap ≥2 次；component 检测保守（避免误报），批 4 接 Component Matcher 时再增强。

## 批 3 交付明细（2026-09-18）
- `llm/provider.py`：LLMProvider 协议 + `MCPSamplingProvider`（createMessage 走 session，超时/重试归 session，**不支持 sampling 的宿主连请求都不发**）+ `RuleFallbackProvider`（确定性启发式，永不抛错）+ `NullProvider`（脚本化）+ `select_provider`（诚实语义：无 capability → None = off）+ `llm_fn_from_provider` 适配 narrative_engine 接缝。
- `mcp/sampling.py`：SamplingSession——负数 id 命名空间（与入站请求 id 永不冲突）、pump 驱动等待（handler 挂起期间入站流量照常流动）、超时+重试、EOF 转 LLMUnavailableError。
- `mcp/server.py`：主循环升级为**双向**——reader 线程 + 队列；initialize 握手记录 `capabilities.sampling`；sampling 响应在请求解析**之前**拦截路由；EOF 哨兵被撞见时**重新入队**（关键修复：一次性哨兵被挂起的 handler 消费后主循环会永久阻塞）。
- `mcp/tools.py`：ToolContext 增 session；新工具 **`ppt_agent_narrative_plan`**（第 18 个）：sampled / fallback / off 三态在 metadata.llm 中披露。
- 测试：13 项 provider 单测 + 4 项 stdio 端到端（sampled/off/timeout-fallback/error-fallback 全覆盖）+ 既有工具集断言 17→18。
- 实测结论（重要）：`sampling/createMessage` 的端到端链路已用脚本化假宿主完整验证；**真实宿主（WorkBuddy/hermes）是否声明 sampling capability 仍未实测**——运行时行为已就绪，宿主不支持时自动 off 且披露。
